# Source dossiers

Pass 1 is a provenance-and-credit pass. Each source gets its own directory before any synthesis is attempted.

## Core books

1. [`fulton-young-tableaux/`](fulton-young-tableaux/) — William Fulton, *Young Tableaux: With Applications to Representation Theory and Geometry*.
2. [`fulton-harris-representation-theory/`](fulton-harris-representation-theory/) — William Fulton and Joe Harris, *Representation Theory: A First Course*.
3. [`sagan-symmetric-group/`](sagan-symmetric-group/) — Bruce E. Sagan, *The Symmetric Group: Representations, Combinatorial Algorithms, and Symmetric Functions*.
4. [`james-kerber-symmetric-group/`](james-kerber-symmetric-group/) — Gordon D. James and Adalbert Kerber, *The Representation Theory of the Symmetric Group*.
5. [`serre-linear-representations-finite-groups/`](serre-linear-representations-finite-groups/) — Jean-Pierre Serre, *Linear Representations of Finite Groups*, translated by Leonard L. Scott.
6. [`diaconis-group-representations-probability-statistics/`](diaconis-group-representations-probability-statistics/) — Persi W. Diaconis, *Group Representations in Probability and Statistics*.

Serre supplies the compact general finite-group backbone; Diaconis then pushes representation theory directly into probability, permutation/ranking data, spectral analysis, ANOVA, invariant metrics, and statistical models. Keep those two adjacent when following the regression-on-the-symmetric-group thread.

## Mirroring policy used in this pass

None of the sources above is mirrored here. The books are publisher-controlled works. The shorter PDFs are legitimately available from author or university pages, but no explicit redistribution license was found in the PDFs during this pass. Publicly readable is not the same thing as permission to republish, so the repository links to legitimate hosts instead.

For Diaconis, the Stanford Statistics technical-report record and Stanford Digital Repository are authoritative institutional pointers, but the 1988 IMS monograph itself states copyright/all-rights-reserved. The 1987 technical report should also be treated as a related earlier version unless exact version identity and redistribution permission are established.

If a later source carries an explicit permissive license or is clearly public domain, a local copy may be added together with the exact license/provenance record.
