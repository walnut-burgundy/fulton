# Intersection Theory

**William Fulton. *Intersection Theory*, 2nd ed., Springer, 1998.**

Publisher/DOI: https://doi.org/10.1007/978-1-4612-1700-8

## Role in this repository

This is a primary Fulton source and the systematic intersection-theory counterpart to the Eisenbud–Harris reading path.

Topics to index across the repository include rational equivalence, Chow groups, divisors, vector bundles, Chern classes, intersection products, normal cones/bundles, excess intersection, and Riemann–Roch.
